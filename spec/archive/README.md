# 归档（Archive）

> 存放**已废弃 / 已被替代 / 已完成并合入**的规格与变更。归档内容只作历史依据，不代表当前有效约定。

---

## 目录约定

```
spec/archive/
├── README.md
├── current/     # 被替代的旧版功能规格（移自 ../current/）
└── changes/     # 已完成并合入的变更记录（移自 ../changes/）
```

## 归档规则

1. **只移不删**：文件移入归档后原样保留，不修改正文。
2. **标注替代关系**：在归档文件头部补一行
   `> 已于 YYYY-MM-DD 被 [xxx](../current/xxx.md) 替代，本文件仅作历史依据。`
3. **编号不回收**：归档文件占用的 `NNN` 编号不再分配给新文档。
4. **决策记录不归档**：`../decisions/` 的 ADR 永久保留，仅在被新 ADR 替代时把状态改为 `已被 NNN 替代` 并注明指向。
