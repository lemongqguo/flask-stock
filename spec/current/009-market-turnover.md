## 1. 场景与口径

把 A 股**沪 / 深 / 北三市每日总成交额**（1990 年至今）入库并做页面展示。统计口径以用户已实测的
`example/fetch_turnover.py` 为准：

| 市场 | 指数 | 东财 secid | 腾讯 secid | 说明 |
| --- | --- | --- | --- | --- |
| 沪市 | 上证指数 | `1.000001` | `sh000001` | 成交额字段即全市场口径 |
| 深市 | **深证成指** | `0.399001` | `sz399001` | 同上（不是 500 只成分股之和；2026-11-12 全量比对佐证） |
| 北证 | 北证50 | `0.899050` | `bj899050` | 2022-04-29 发布前无指数级成交额，留 NULL |

- **合计 = 三市之和（缺失按 0），不含基金、债券**；缺失值（北证早期 / 深市 1991-07 开业前）保留 NULL，
  绝不伪造成 0——「没数据」和「成交为零」是两回事。
- **单位亿元**，`DECIMAL(18,4)` 四位小数，与历史 CSV 完全一致，导入无损；采集源返回元（腾讯万元），入库前统一换算。

## 2. 数据源约定

| 项 | 约定 |
| --- | --- |
| 主源 | 东方财富 push2his 历史 K 线（`klt=101&fqt=1`，沪深用 `beg=19900101`，北证用 `lmt=100000`——北证带 beg 会被服务端断开） |
| 备源 | 腾讯 newfqkline（`param={secid},day,,{end},2000,qfq`，成交额在第 9 字段、单位万元；向前翻页 2000 条 × 最多 20 页，翻到 1990-12-19 为止） |
| 取数模式（2026-11-13，ADR-008） | **库非空且最新日期距今 ≤100 自然日 → 增量**：东财沪深 `beg=库最新-100自然日`、北证 `lmt=N`；腾讯 `count=N` 单页不翻页（N=max(60, 缺口自然日+10)，通常只取最近约 60 个交易日）。**库空 / 超窗 / CLI `--full` → 全量**（上述原参数） |
| 切换 | `auto`：主源异常（条数不足 / 数据过旧 / 网络错误）自动切备源；`eastmoney` / `tencent` 可强制指定；增量模式下降级编排不变 |
| 校验 | 全量：沪 / 深各 ≥ 8000 条、北证 ≥ 500 条、最新日期距今 ≤ 10 天；增量（`validate_recent`）：三市各 ≥ 1 条、沪市最新距今 ≤ 10 天、**源最新 ≥ 库最新**、**窗口覆盖库最新日期**。不达标判该源不可用 |
| 实现 | `utils/turnover_source.py`：urllib 标准库，**无新依赖、无需 Token**；只取数 + 校验 + 组装行，不落库 |

## 3. 数据表

`market_daily_turnover`（`database.py` 幂等建表，无存量迁移）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGINT | 主键 |
| trade_date | DATE | 交易日，唯一键 `uk_turnover_date` |
| sh_amount / sz_amount / bj_amount | DECIMAL(18,4) NULL | 三市成交额（亿元），缺失 NULL |
| total_amount | DECIMAL(18,4) NOT NULL | 合计（亿元） |
| source | VARCHAR(16) | 数据来源：`CSV导入` / `东方财富` / `腾讯行情` |
| created_at / updated_at | TIMESTAMP | 创建 / 更新时间（ON UPDATE） |

## 4. 写入路径（三条共用幂等 upsert）

- **幂等**：`ON DUPLICATE KEY UPDATE`（`trade_date` 唯一键），`execute_many` 单连接批量执行；
  当日盘中快照允许被收盘终值覆盖。
- **CSV 导入**：`flask import-turnover [csv路径]`（默认 `example/A股每日成交额_1990至今.csv`）。
  先整体校验再写入：表头 / 日期格式与唯一 / 数值非负 / 合计=分量和（容差 0.0002 亿），
  **任何一行不合法即整体拒绝**，不做部分导入。
- **日常同步（2026-11-13 起智能模式）**：`flask sync-turnover [--source auto|eastmoney|tencent] [--full]`，
  或页面「同步数据」按钮（`POST /stock/market/api/sync`，冷却 `TURNOVER_SYNC_COOLDOWN` 默认 60s，失败也计入冷却）。
  **库非空走增量、库空走全量**；`--full` 强制全量校准（建议每月一次，收敛窗口外的历史修正）。
  同步 summary 带 `mode: incremental/full`。
- **自动同步（2026-11-13 起）**：监控线程 `_maybe_sync_turnover()` 默认每 3h 一次
  （`TURNOVER_AUTO_SYNC_ENABLED` / `TURNOVER_AUTO_SYNC_INTERVAL`），走增量；**空库跳过**
  （历史全量应 CSV 导入或手动同步，防无人值守口径污染）；失败也计间隔；详见 [004 §3.2](./004-monitor-service.md)。
- **备源 60 日写入保护（仅全量路径）**：腾讯早年历史与东财口径差异大（2026-11-12 全量比对：早年 9267 处差异，
  近 60 个交易日除当日盘中快照外零差异）——**全量 + 库非空 + 腾讯源时只 upsert 最近 60 个交易日**，
  更早数据不动；库为空时备源可全量写入（口径风险在页面与文档注明）。
  增量路径取数窗口本身即保护（只取最近约 60 个交易日），不叠加裁剪。

## 5. 页面与路由

蓝图 `market_bp` 挂 `/stock/market`，全部 `login_required`：

| 路由 | 方法 | 说明 |
| --- | --- | --- |
| `/stock/market/` | GET | 市场成交额页（**只读库**，加载 / 区间切换不打外部接口） |
| `/stock/market/api/turnover` | GET | 页面数据：全部历史 + 统计，与 example data.json 同构；表为空返回 `{"empty": true}` |
| `/stock/market/api/sync` | POST | 手动同步（auto），冷却期内 429；失败 502 且记日志 |

页面结构（`templates/market_turnover.html`，2026-11-12 看板改版按用户模板 `logs/index.html` 移植，见 [看板改版变更](../changes/2026-11-12-market-turnover-dashboard.md)）：

- **顶栏**：标题「A股成交额」（副标三指数口径）+ 数据源徽标 + 更新时间 + 「同步数据」按钮（空态也可用）；
- **hero**：最新交易日合计以**万亿大数字**展示（两位小数）+ 历史排名 / 共 N 个交易日；
  右侧 **6 指标卡**：沪市 / 深市 / 北证 / 近 20 日均值 / 历史峰值（带日期）/ 较前一交易日（百分比）；
- **走势图**：**自绘 canvas，零外部依赖**（[ADR-007](../decisions/007-turnover-dashboard-self-drawn-canvas.md)）；
  **六档交易日区间** 1月 / 3月 / 6月 / 1年 / 3年 / 全部（22/66/130/245/735/0，默认 1年，
  以**库内最新日期**为锚点往前推，数据旧时区间仍有效）；**滚轮缩放**（最少 20 点、光标位置锚定）/
  **拖拽平移** / **悬停明细**（十字线 + 合计与三市四值 tooltip）；只画淡横向参考线，
  **不画竖向网格与轴边框**（D-16）；颜色走 `--mk-*` CSS 变量（双主题），不借用 `--up/--down` 语义色
  （仅「较前一日」百分比用涨跌色）；**主题切换自动重绘**（MutationObserver 监听 `data-theme`，
  D-16 约定延续，不同于 008 K 线图的「切主题需刷新」约定）；
- **60s 自动刷新**：只打本站 API（`document.hidden` 跳过），保留当前窗口大小锚定最新；
  网络异常保留上一次画面，首载失败才显性提示；
- **页脚口径**：常驻注明口径、北证边界、盘中快照语义；**明细表已移除**（明细进悬停 tooltip）；
- **空态显性化**：表为空显示两种入库指引（CSV 导入 / 同步按钮），不渲染假数据；缺失渲染「—」不渲染 0。
- **平铺自适应（2026-11-12 用户反馈）**：不设宽度上限，随 `.content` 全宽铺开；图表卡纵向撑满剩余高度
  （flex 链，与 `.card-fill` 同约定，图表最小 300px / 窄屏 260px）；≥1500px 宽屏 6 指标卡单行平铺；≤900px 堆叠。

侧栏：新增大项「**行情**」（位于交易与监控之间），首项「市场成交额」（`base.html`，四组结构）。

## 7. 验收条件

1. `flask import-turnover` 幂等导入 CSV，重复执行不增行；非法 CSV 整体拒绝。
2. `flask sync-turnover` / 页面按钮真实同步成功，auto 模式主源失败自动降级备源；
   库非空走增量（summary `mode=incremental`），库空 / 超窗 / `--full` 走全量。
3. 全量 + 库非空时腾讯备源只写最近 60 个交易日，更早历史不被覆盖；增量不叠加裁剪。
4. 页面 hero / 指标卡 / 走势图全部来自数据库；缺失值显示「—」；空态显示入库指引。
5. `python -m unittest tests.test_market_turnover -v` 全部通过（47 用例）。
6. `python -m unittest tests.test_shell_layout -v` 全部通过（4 用例：侧栏四组折叠控件 / 多按钮同步 / 全宽平铺 / 图表撑满）。
7. `python -m unittest tests.test_turnover_auto_sync -v` 全部通过（10 用例：开关 / 到点 / 空库守护 / 失败也计间隔 / 间隔下限 / 非法间隔回落默认 / 退避前调用契约）。
8. 监控线程每 `TURNOVER_AUTO_SYNC_INTERVAL` 秒自动增量同步一次；空库跳过并日志提示；失败不中断主循环。

## 8. 已知限制

- **本机网络东财不可达**（2026-11-12 实测 RemoteDisconnected），日常路径实际是腾讯备源 + 60 日保护；
  历史全量依赖 CSV 导入（东财口径）。东财主源成功路径未在本环境验证。
- **北证 2022-04-29 前合计不含北交所**：北交所 2021-11-15 开市至指数发布前的成交额无法从指数级接口获得，
  页面与文档显式注明，不伪造数据。
- 口径依赖数据源「成交额字段即全市场」这一事实；若东财/腾讯调整字段口径，合计会失真——
  靠 `validate()` 条数与新鲜度校验 + 页面展示数据源与更新时间发现异常。
- 同步冷却状态在进程内存，多进程部署失效（项目强制单进程 gunicorn workers=1）。
- 当日盘中同步得到的是累计快照，收盘后需再次同步覆盖为终值（CSV 最后一行即盘中快照的实例）。
- **增量窗口外的历史修正发现不了**（2026-11-13，ADR-008）：60 交易日以前的源数据修正增量不可见——
  靠 `flask sync-turnover --full` 月度校准兜底，页面数据源与更新时间徽标辅助发现异常。
- **增量依赖库内最新日期正确**：库被污染（未来日期）时「源最新 ≥ 库最新」校验会判源不可用，
  同步失败进日志，不会静默写错；修复走 `--full` 或 CSV 重导。
- 自动同步已接监控线程（默认 3h，可配），但**空库不自动初始化**——历史全量仍需 CSV 导入或首次手动同步；
  自动同步状态仅日志 + `get_status()` 字段，未接 UI（T-05 范畴）。
