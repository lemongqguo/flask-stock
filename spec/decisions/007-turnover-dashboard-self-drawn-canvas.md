# ADR-007：市场成交额图表自绘 canvas（按用户模板移植）

**状态**：已接受　|　**日期**：2026-11-12
**关联规格**：[009 市场成交额](../current/009-market-turnover.md)
**关联变更**：[2026-11-12 市场成交额看板改版](../changes/2026-11-12-market-turnover-dashboard.md)

## 背景

用户要求把市场成交额页按其喜欢的 `logs/index.html` 模板原样移植。模板的走势图是**自绘 canvas**：
滚轮缩放 / 拖拽平移 / 悬停明细 / 六档交易日区间，另有万亿大数字 hero 与 6 指标卡。
既有页面用 Chart.js 4.4.1（与 K 线页同款锁定版本），原生不支持滚轮缩放 / 拖拽平移。
需要定下改版后页面的图表技术。

## 比较过的方案

1. **Chart.js + chartjs-plugin-zoom**：复用既有依赖，但需新引 CDN 插件（zoom/pan），且交互手感仍与模板有差距
   （tooltip 样式、十字线、区间语义都要深度定制）；给本页增加一个外部依赖，离线能力倒退。
2. **移植模板自绘 canvas**：零依赖、离线可用，交互与模板原样一致（缩放/平移/悬停/DPR 适配模板已验证）；
   代价是约 300 行绘制代码自维护。
3. **换 ECharts 等更重图表库**：缩放平移开箱即用，但引入全新大依赖，与项目「去 CDN、自建设计系统」
   的既定方向（ADR-002）冲突，单走势图场景过度。

## 决策

**取方案 2：移植模板自绘 canvas**。市场成交额页零外部图表依赖；Chart.js 4.4.1 **仅保留 K 线页**
（008 约定相应收窄）。绘制颜色全部经 `cssVar('--mk-*')` 读双主题变量，切主题 MutationObserver 重绘
（延续 D-16）；只画淡横向参考线，不画竖向网格与轴边框（延续 D-16「无表格框」）。
核心交互由 4 个模板契约用例锁死（六档区间 / 缩放平移悬停 / 主题重绘 / 零 CDN）。

## 代价与后续

- **绘制代码自维护**：缩放/平移/悬停/resize/DPR 全部页内实现，无社区生态可依赖；
  缓解：契约测试 + 真实浏览器 9 项验证。未来若需更复杂图表（多轴 / K 线叠加）再评估引库。
- **分市场视图移除**：模板为单合计线；分市场数值进悬停 tooltip（四值），
  用「一眼看三市走势对比」换模板原样观感。若用户后续要分市场走势线，另立变更。
- **明细表移除**：最近 20 日明细进悬停 tooltip 与 hero 指标卡；需要表格数据的用户走 CLI / 库。
- K 线页的 Chart.js CDN 依赖与「切主题需刷新」约定**不变**，两页图表技术本次不强行统一（避免扩大影响面）。
