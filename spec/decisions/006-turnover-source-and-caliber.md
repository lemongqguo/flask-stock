# ADR-006：市场成交额的数据源、统计口径与存储形态

**状态**：已接受　|　**日期**：2026-11-12
**关联规格**：[009 市场成交额](../current/009-market-turnover.md)
**关联变更**：[2026-11-12 市场成交额](../changes/2026-11-12-market-turnover.md)

## 背景

用户需要把 A 股**沪 / 深 / 北三市每日总成交额**（1990 年至今）入库并做页面展示。
用户已提供经过实测的 `example/fetch_turnover.py`（东财主源 + 腾讯备源）与拉好的历史 CSV，
并明确：**数据源逻辑复用 example，统计口径以 example 为准**。

需要定下来的取舍：数据源选谁、深市用哪个指数、单位与表结构、备源写入范围。

## 决策

1. **数据源：东财 push2his 主源 + 腾讯 newfqkline 备源**，原样复用 example 的解析与校验逻辑
   （`utils/turnover_source.py`，urllib 标准库，无新依赖、无需 Token）。
   主源异常（条数不足 / 数据过旧 / 网络错误）自动切备源。
2. **统计口径（与 example 完全一致）**：
   - 沪市 = 上证指数（东财 `1.000001` / 腾讯 `sh000001`）；
   - 深市 = **深证成指**（`0.399001` / `sz399001`）——东财/腾讯该指数的成交额字段即**全市场口径**，
     不是 500 只成分股的成交额（2026-11-12 抽查：腾讯 11-10/11 两日三市数值与用户 CSV 完全一致）；
   - 北证 = 北证50（`0.899050` / `bj899050`），2022-04-29 发布前无指数级成交额，留 NULL；
   - 合计 = 三市之和（缺失按 0），不含基金、债券。
3. **存储：新表 `market_daily_turnover`，单位亿元 `DECIMAL(18,4)`**，`trade_date` 唯一键，
   `ON DUPLICATE KEY UPDATE` 幂等 upsert。亿元 4 位小数与 CSV 完全一致，导入无损；
   当日盘中快照允许被收盘终值覆盖。
4. **备源 60 日写入保护**：腾讯早年历史与东财口径差异大，库非空时备源只 upsert 最近 60 个交易日，
   更早数据不动（对齐 example `write_csv` 的 protect 语义）；库为空时备源可全量写入。

## 代价

- **口径依赖数据源的"成交额字段即全市场"这一事实**：若东财/腾讯未来调整字段口径，合计会失真。
  缓解：`validate()` 的条数与新鲜度校验 + 页面展示数据源与更新时间，便于发现异常。
- **本机网络东财不可达**（2026-11-12 实测 RemoteDisconnected），日常路径实际是腾讯备源 + 60 日保护——
  历史全量依赖 CSV 导入（东财口径），这正是用户先拉好 CSV 的原因。
- **北证 2022-04-29 前合计不含北交所**：北交所 2021-11-15 开市至指数发布前的成交额无法从指数级接口获得，
  页面与文档显式注明，不伪造数据。
- 同步冷却状态在进程内存（与告警冷却 T-02 同类），多进程部署会失效——项目当前强制单进程（gunicorn workers=1），可接受。

## 被否决的方案

- **雪球接口（项目现有 pysnowball）**：已实测 `quote_detail` / `kline` 能取沪深成交额
  （SH000001 + SZ399106，kline 单次 1500 条覆盖 6 年），但：① 用户明确指定复用 example 逻辑与口径；
  ② 雪球历史深度有限（约 6 年+），拿不到 1990 年起的全量；③ 北证50 在雪球的可用性未验证；
  ④ 雪球 Token 会过期（本机根目录 Token 已 400016），东财/腾讯无需凭据更省心。
- **深市用深证综指（SZ399106）**：雪球口径下综指覆盖更全，但 example 在东财/腾讯口径下实测
  深证成指成交额即全市场，且用户 CSV 已按此口径拉好——换综指会与历史数据产生口径断裂。
- **复用 `stock_bench_kline` 加 amount 列**：该表语义是"基准指数收盘价"（按 bench_code 区分），
  成交额是市场级日频数据而非基准行情，混入会让两类查询互相干扰；新表语义干净、迁移为零。
- **金额存"元"（BIGINT/DECIMAL(20,2)）**：与 CSV 的亿元 4 位小数换算引入舍入误差，
  页面展示还要再除一次；亿元存储与源文件、展示单位三方一致。
