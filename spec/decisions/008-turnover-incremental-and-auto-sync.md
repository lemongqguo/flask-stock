# ADR-008：成交额增量同步窗口与监控线程自动同步

**状态**：已接受　|　**日期**：2026-11-13
**关联规格**：[009 市场成交额](../current/009-market-turnover.md)、[004 后台监控服务](../current/004-monitor-service.md)
**关联变更**：[2026-11-13 增量同步 + 自动同步](../changes/2026-11-13-turnover-incremental-auto-sync.md)
**前置决策**：[ADR-006 数据源、统计口径与存储形态](006-turnover-source-and-caliber.md)

## 背景

009 首版每次同步都全量拉取 1990 年至今全历史（东财 3 指数 × 约 8800 行；腾讯约 15 次翻页），
库已有全量后日常更新只需最近几天，全量纯属浪费（用户反馈）。同时首版无自动同步，
每日更新靠手动按钮 / CLI。用户要求：增量取数 + 挂进监控线程每 3 小时自动跑一次。

## 比较过的方案

**取数范围**：

1. **每次全量（现状）**：实现最简单、能收敛任意历史修正；但日常更新数据量放大两个数量级，被用户否决。
2. **只取当天**：最省；但漏同步几天就出缺口、盘中快照无法覆盖为终值、源修正近几天历史无法收敛，否决。
3. **增量窗口（取）**：库非空时只取「库内最新日期前推 100 自然日至今」（通常约 60 个交易日）。
   窗口与备源 60 日保护统一语义：**日常同步只碰最近约 60 个交易日**；
   缺口 ≤100 自然日时窗口自动放大覆盖（腾讯/北证条数 N=max(60, 缺口+10)），超窗回退全量。

**自动同步调度**：

1. **外部 cron 调 CLI**：零代码；但引入部署依赖（每台机器要配 crontab），与项目自包含方向不符，
   且状态不可见（页面/日志看不到调度情况），作为备选保留。
2. **监控线程挂钩（取）**：`_maybe_sync_bench`（每交易日一次）与 `_maybe_send_daily_summary`（每天一次）
   已是现成范式；线程单例（D-05）+ 强制单进程天然防重；随应用启动零部署依赖；状态可进 `get_status()`。
3. **独立调度线程**：多一个线程的生命周期/退出管理，与现有「旁路任务挂主循环」结构重复，否决。

## 决定

1. **增量取数**：东财沪深动态 `beg`（库最新 -100 自然日）、北证 `lmt=N`；腾讯 `count=N` 单页不翻页。
   校验分流：全量 `validate()` 不变；增量 `validate_recent()`（三市各 ≥1 条、沪市最新 ≤10 天、
   源最新 ≥ 库最新、窗口覆盖库最新）。auto 降级编排不变。
2. **全量仅三入口**：空库初始化 / 超窗（>100 自然日）回退 / CLI `--full` 校准（建议每月一次）。
   全量 + 腾讯 + 库非空的 60 日写入保护（ADR-006）原样保留；增量窗口本身即保护，不叠加裁剪。
3. **监控线程自动同步**：`_maybe_sync_turnover()` 默认每 10800s（3h）一次，
   `TURNOVER_AUTO_SYNC_ENABLED` / `TURNOVER_AUTO_SYNC_INTERVAL` 可配；
   **到点即置位、失败也计间隔**（交易时段轮间隔为 0，防重试风暴）；**空库跳过**（防无人值守口径污染）；
   调用点在雪球退避检查之前（成交额源与雪球 Token 无关）；异常隔离不中断主循环。
4. **页面按钮智能模式**：库非空增量、库空全量，UI 与 60s 冷却不变；全量选项只暴露给 CLI。

## 代价与后续

- **窗口外的历史修正发现不了**：60 交易日以前的源数据修正增量不可见——靠 `--full` 月度校准兜底，
  页面数据源与更新时间徽标辅助发现异常。
- **增量依赖库内最新日期正确**：库被污染（未来日期）时「源最新 ≥ 库最新」校验会判源不可用，
  同步失败进日志，不会静默写错；修复走 `--full` 或 CSV 重导。
- **东财增量路径本机未验证**（本机东财不可达，ADR-006 已注明）；腾讯增量参数与全量同接口同字段，
  仅条数不同，风险低。
- **监控轮内联阻塞有界**：增量正常 3 个小请求秒级；极端受 `http_json` 30s 超时 + `SOCKET_TIMEOUT` 兜底，
  每 3h 一次可接受；停止语义与 bench 同步一致（`_stop_event` + 看门狗）。
- 自动同步状态目前仅日志 + `get_status()` 字段，未接 UI（T-05 运行时控制面待办范畴）。
