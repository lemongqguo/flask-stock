# ADR-002：前端移除 Bootstrap，改用自建设计系统

**状态**：已接受　|　**日期**：2026-10-21　|　**相关变更**：[2026-10-21 前端 UI 改版](../changes/2026-10-21-frontend-redesign.md)

---

## 背景

现有页面基于 Bootstrap 5 + jQuery + Font Awesome CDN。改版需求要求"交易终端"风格（深色优先、信息高密度、红涨绿跌），视觉效果与 Bootstrap 默认样式差异较大。

## 决策

1. **移除 Bootstrap CSS / JS 与 jQuery**，改用 `static/css/theme.css` 自建设计系统（设计令牌 + 网格 + 组件）。
2. **移除 Font Awesome CDN**，改为内联 SVG sprite。
3. **保留 Chart.js 4.4.1**（K 线图依赖，版本已锁定）。
4. 提供**深色 / 浅色双主题**，同一套 CSS 变量切换，右上角按钮 + `localStorage` 记忆，默认深色。

## 理由

- 目标视觉与 Bootstrap 默认风格差异大，保留意味着大量 `!important` 覆盖与类名冲突，维护成本高于收益；
- 现有 `static/css/style.css` 仅 193 行，改造量可控；
- 移除 CDN 后**离线可用**，少两个外部请求，也避免 CDN 不可达导致图标丢失；
- 双主题用 CSS 变量实现，成本接近零，用户可自选。

## 代价与风险

- 后续若需要复杂组件（如日期选择器）需自行实现或按需引入；
- 图表仍依赖 Chart.js CDN，未彻底离线化（K 线图为核心功能，暂不替换）；
- 项目无 UI 自动化测试（T-01 未闭环），改版正确性依赖人工核对。

## 备选方案（未采用）

- **保留 Bootstrap 仅做定制**：改造期短，但长期背负覆盖成本与"Bootstrap 味"，且难以支持双主题。
- **引入 Tailwind 等框架**：需新增构建步骤，与当前"静态文件直出"的部署方式冲突。
