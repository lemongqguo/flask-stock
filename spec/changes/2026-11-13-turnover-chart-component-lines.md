## 1. 问题与动机

走势图只画「沪深北合计」一条线，沪 / 深 / 北三市分量只能靠悬停 tooltip 逐日查看，
无法直观对比三市走势与结构变化。用户要求：把沪深北三条分量线也画出来，
**比合计线细一点**，**图例放在 x 轴下面**。

## 3. 旧约定 → 新约定

| 项 | 旧约定 | 新约定 |
| --- | --- | --- |
| 线条 | 仅合计一条主线（2px，`--mk-accent`）+ 面积填充 | 合计主线不变；新增沪 / 深 / 北三条分量线（**1.25px**，`--mk-sh` / `--mk-sz` / `--mk-bj`），**先画分量后画主线**（主线在最上层）；面积填充仍只跟随合计 |
| Y 轴范围 | 仅按合计 min/max ±12% | 按四条线**非空值**共同 min/max ±12%（否则 1 年视图下分量全部跌出绘图区不可见） |
| 缺失值 | 分量 null 仅 tooltip 显示「—」 | 分量 null 处**断线不连、不画点**（北证 2022-04-29 前 / 深市开业前），不伪造 0 |
| 图例 | 无 | canvas 下方（x 轴日期标签之下）HTML 图例四项：沪深北合计 / 沪市 / 深市 / 北证；色条粗细呼应线宽（合计 3px / 分量 2px），颜色随主题变量 |
| 悬停 | 十字线 + 合计点（r4，`--mk-cyan`）+ tooltip 四值 | 增加分量点（r2.5，null 跳过）；各点用各自线色（合计点改用 `--mk-accent`）；tooltip 行首加同色圆点 |
| 单点窗口 | 只 moveTo 不描边（不可见） | 单点时各系列画点（分量 r2.5 / 合计 r4） |

## 5. 实施要点

1. **分量色**：沪 cyan / 深 amber / 北 pink，与合计蓝主色色相、明度均分离；
   暗 `#22d3ee / #fbbf24 / #f472b6`，亮 `#0891b2 / #d97706 / #db2777`
   （亮色深一档保证可读性，色相与暗色一致——与 kline 配色同约定）。
2. **共享线性 Y 轴**：否决双轴（误读风险）与归一化（丢失量级），均违背「诚实口径」；
   分量与合计同轴直接可比，北证量级小贴近底部为如实呈现。
3. **图例用 HTML** 而非 canvas 内绘制：文本清晰、主题随 CSS 变量自动切换、
   不改 canvas 布局与 PAD；flex 链中 `flex: 0 0 auto`，图表仍撑满剩余高度。
4. **分量线路径遇 null 断笔**（moveTo 重启），绝不跨缺失连线。
5. **悬停点与 tooltip 圆点同色映射**，读图不靠猜。
