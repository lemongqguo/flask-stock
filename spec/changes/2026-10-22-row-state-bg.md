# 变更：告警行 / 暂停行专属背景（多色渐变 + 流动）

| 项 | 内容 |
| --- | --- |
| 状态 | **已合入**（渐变观感待人工确认） |
| 类型 | 新增能力（状态可视化） |
| 触发 | 用户：给所有行加的淡色底效果不好（已回退），改为**只给告警行/暂停行加专属背景**；随后要求**改成渐变色，可多色叠加，从左侧浅浅地丝滑滑入、到右侧边缘终止** |
| 关联规格 | [002 股票订单管理](../current/002-stock-order.md)、[008 前端 UI](../current/008-frontend-ui.md) |
| 验证 | 全量 **289 用例通过**（`tests/test_table_row_style.py` 19 个，含"普通行不得有底色"的防回潮断言）；真实页面核对：首页 10 条中出现 `data-alarm="alarm"` 2 次 |

## 1. 原则

**底色用来表达状态，不是装饰**。普通行保持卡片原色——给所有行铺淡色底的尝试已回退，
见 [2026-10-22 表格行淡色底](./2026-10-22-table-row-bg.md)。

## 2. 实现：渐变（多色叠加，左起渐隐）

模板行上已有 `data-status`（active/inactive）与 `data-alarm`（`alarm` / 空），按属性选择器上色，无需改模板。

| 状态 | 选择器 | 效果 |
| --- | --- | --- |
| 告警中 | `tr[data-alarm="alarm"]` | `--alarm-grad` 多色渐变 + `alarm-flow` 流动 + `alarm-breathe` 呼吸 |
| 已暂停 | `tr[data-status="inactive"]` | `--idle-grad` 中性灰蓝渐变（静态）+ `opacity: .62` |
| 普通 | — | 无底色（hover 时 `--surface-2`） |

告警渐变（暗色）：`红 rgba(255,77,79,.30) → 琥珀 rgba(245,165,36,.18) → 紫 rgba(139,124,255,.10) → 透明 0`，
**终点透明**，所以渐变在右侧边缘自然收尾。亮色同构、透明度略低。

流动怎么来的：渐变横向铺 **220%** 宽，`background-position` 从 `0%` 走到 `200%`，
因此看起来是"从左边浅浅地滑入、一路向右滑过"。`background-size` 必须大于 100%，否则没有位移余量。

## 3. 三个实现约束（都写进用例了）

1. **呼吸只能改 `opacity`，不能改 `background`**——渐变占了 `background`，改它会把渐变冲掉。
2. **两个动画改不同属性**（`background-position` / `opacity`）才能共存，`animation:` 多值用逗号分隔。
3. **sticky 操作列必须用等效实色**（`--alarm-bg-1`）：渐变在右缘已渐隐到透明，
   而 sticky 单元格自带不透明背景，跟着渐变走就会在横向滚动时透视下层列的内容。
   操作列**不跑自己的动画**——呼吸由 `tr` 的 opacity 统一作用于整行，各自为政必然不同步。

hover 处理：`animation: none, alarm-breathe ...` **只停流动、保留呼吸**（渐变无法叠加半透明层），
背景换成更浓的 `--alarm-grad-hover`；暂停行 hover 恢复 `opacity: 1`，否则按钮也跟着淡、不好点。

`prefers-reduced-motion: reduce` 下不流动也不呼吸，渐变静态铺满（`background-size: 100%`）。

## 4. 验证

真实页面核对：

```
首页 10 条（全库告警中 8 条、已暂停 16 条）
页面出现 data-alarm="alarm": 2   → 渐变/呼吸可见
页面出现 data-status="inactive": 0 → 首页这 10 条里没有暂停订单
```

**注意**：暂停行要翻到含暂停订单的页才看得到（全库 16 条暂停，首页前 10 条都是监控中）。

## 5. 未验证

- 渐变观感（配色、4.5s 流动周期、2.6s 呼吸节奏）需用户看一眼；
- 同一行既是告警又是暂停不会出现（暂停订单不参与告警判定），未做优先级处理。

## 6. 可调参数

| 想改什么 | 调哪里 |
| --- | --- |
| 配色/浓淡 | `--alarm-grad` / `--alarm-grad-hover` / `--idle-grad`（两个主题各一套） |
| 流动快慢 | `alarm-flow 4.5s`（越大越慢） |
| 呼吸快慢/幅度 | `alarm-breathe 2.6s` 与 keyframes 里的 `opacity: .84` |
| 渐变覆盖范围 | `background-size: 220%`（越大，一次滑过的距离越长） |
