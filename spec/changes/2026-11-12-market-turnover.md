## 5. 实施要点

1. **口径以 example 为准**：深市用深证成指而非深证综指——example 实测东财/腾讯的成交额字段即全市场口径（本项目抽查腾讯 2026-11-10/11 两日三市数据与 CSV 完全一致）。取舍见 [ADR-006](../decisions/006-turnover-source-and-caliber.md)。
2. **单位亿元 DECIMAL(18,4)**：与 CSV 四位小数一致，导入无损；采集源返回元（腾讯万元），入库前统一换算。
3. **幂等 upsert**：`ON DUPLICATE KEY UPDATE`（`trade_date` 唯一键），当日盘中快照可被收盘终值覆盖更新；CSV 导入与日常同步共用同一入口。
4. **备源 60 日保护**：库非空 + 腾讯源时只写最近 60 个交易日；库为空时备源可全量写入（口径风险在页面与文档注明）。
5. **页面只读库**：与「刷新行情」同一约定——页面加载 / 区间切换不打外部接口；只有「同步数据」按钮（POST，60s 冷却）与 CLI 才请求东财/腾讯。
6. **图表**：Chart.js 4.4.1（与 K 线图同款锁定版本，加载失败降级文字提示）；颜色走新增 `--turnover-*` CSS 变量（双主题），不借用 `--up/--down` 语义色；页面专属脚本按 K 线图先例放 `{% block scripts %}`。
7. **空态显性化**：表为空时页面显示导入/同步指引，不渲染假数据；缺失值（北证早期）渲染「—」不渲染 0。
8. **CSV 校验结论**（2026-11-12 实测）：8807 行严格升序无重复；合计=分量和（容差 0.0002 亿）零偏差；北证边界正确；45 个周末日期与 92 个深市缺值均为早期市场真实历史（1991 年沪市周六休市、深市 1991-07 前未开业）；**最后一行 2026-11-12 为盘中快照**（沪 7517 亿 vs 当日 14:54 腾讯 8574 亿），导入后需收盘同步覆盖。
9. **本机网络东财不可达**（RemoteDisconnected），auto 模式会自动降级腾讯——降级路径即本环境的日常路径，已纳入真实验证。

## 8. 合入后缺陷修复（D-16，2026-11-12）

**现象**：浅↔深切换主题后，走势图在深色背景上残留浅色「表格框」（网格 + 轴边框），tooltip 亦为白底；刷新后消失。

**根因**：图表颜色只在 `draw()` 时经 `cssVar()` 取一次，而 `theme.js` 的 `applyTheme` 只改 `data-theme` 属性、不重绘图表。
浅→深切换后画布保留浅主题的网格色 `--border-soft: #eef2f7` 与 tooltip `--surface: #ffffff`，暴露在深色背景上；
刷新按深色主题重绘故「刷新就没了」。

**修复**（`templates/market_turnover.html`）：
1. x/y 两轴关闭网格与轴边框（`grid` / `border` 均 `display: false`）——表格框按用户要求彻底去除，刻度标签保留；
2. 新增 `MutationObserver` 监听 `document.documentElement` 的 `data-theme`，主题切换后按新主题色重绘
   （刻度/图例/tooltip/线色全部随主题）。不同于 008 K 线图「切主题需刷新」的约定，本页即时跟随。

**验证**：
- 真实浏览器 7 状态（深色默认 / 深色 tooltip / 浅色 / 浅色 tooltip / 切回深色 / 分市场+近 1 年浅色 / 切回深色）：
  均无网格与轴边框，tooltip 背景与主题一致（深 `#11161f` / 浅 `#ffffff`），线色随主题正确重绘，console 0 错误；
- 新增 2 个模板契约用例（`ChartTemplateContractTest`，累计 27 全过）锁死无网格 + 主题重绘；
- 验证使用用户自行同步的全量 8807 行数据，**零写入零删除**；临时验证服务（5001 端口）验证后已停止。
