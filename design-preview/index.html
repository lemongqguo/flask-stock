股池监控台 · UI 改版设计稿
方向：交易终端（Trading Terminal）——深色优先、信息高密度、A 股配色（红涨绿跌）、数字等宽对齐。
本目录为纯静态预览，未改动任何现有模板与后端代码。每个页面右上角可切换深色 / 浅色。

三个决策

移除 Bootstrap

新界面是自建设计系统（CSS 变量 + 网格 + 组件）。保留 Bootstrap 只会带来类名冲突、体积与覆盖成本。删除 bootstrap.min.css / bootstrap.bundle.min.js，jQuery 一并移除（现有 main.js 无实际依赖）。

深色 + 浅色双主题

同一套 CSS 变量出两套主题，右上角一键切换并记忆选择（localStorage）。默认深色。图标改用内联 SVG sprite，不再依赖 Font Awesome CDN，离线可用。

覆盖全部 8 类页面

订单列表、订单表单、告警设置、告警历史、指标监控、AI 分析、登录/注册、账户设置。登录注册、个人资料与改密码合并为带页签的单一模板，减少模板数量。

新功能 3：指标监控 —— 判定口径

指标类型判定式参数（默认）数据来源
52 周新低 长期 (现价 − low52w) / low52w ≤ 阈值 IND_LOW52W_NEAR_PCT = 3.0 雪球 quote_detail.low52w
52 周回撤 > 35% 长期 (现价 − high52w) / high52w ≤ −35% IND_DRAWDOWN_52W_PCT = 35 雪球 quote_detail.high52w
20 日跑输市场 15% 短期 ret20(个股) − ret20(基准) ≤ −15% IND_RS20_PCT = 15、IND_BENCH = SH000300 已有 stock_kline 收盘价（无需额外接口）
5 日跌幅 2.5 倍 短期 两者均下跌，且 |ret5(个股)| ≥ 2.5 × |ret5(基准)| IND_RS5_RATIO = 2.5 同上
需你确认口径：「5 个交易日低于市场的 2.5 倍」有两种理解，我按「个股 5 日跌幅 ≥ 基准 5 日跌幅 × 2.5」实现（两者都下跌时才判定）。 另一种可能是「5 日涨跌幅跑输基准 2.5 个百分点」——若是这个意思，请告知，改动只是换一个判定式 + 一个参数名。

新功能 4：AI 分析 —— 预留设计

页面三栏：标的列表 → 报告 → 参数/历史。报告固定结构为 评级 + 置信度 + 核心结论 + 关键要点 + 支撑/风险 + 免责声明，底部支持追问。

输入数据全部来自系统已有表（行情、PE/PB、stock_indicator、stock_kline）， 不额外抓数据；分析结果建议落库 stock_ai_report（stock_master_id、model、prompt_version、verdict、confidence、content_json、created_at），便于复盘与计费统计。

配置项建议：AI_ENABLED、AI_API_BASE、AI_API_KEY、AI_MODEL、AI_TEMPERATURE、AI_MAX_TOKENS、AI_MONTHLY_LIMIT。 未配置时页面显示「未启用」而不是报错。
