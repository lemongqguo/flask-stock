## 一、策略总体框架

该策略为「**低估值 + 超跌**」双维度左侧筛选模型，把 6 个指标分为两组：

| 维度 | 包含指标 | 回答的问题 | 判定方式 |
| --- | --- | --- | --- |
| 长期估值条件（3 项） | PE、PB、市值/经营现金流 | 股票便不便宜？ | 历史分位 ≤ 10% |
| 短期超跌条件（3 项） | 52 周回撤、20 日相对沪深300、5 日 Z 分数 | 短期跌得够不够狠？ | 绝对幅度阈值 |

信号触发后仍需两道确认：

1. **价格确认**：等待自低点反弹 5% 后再入场（左侧信号防接飞刀）；
2. **人工复核**：基本面人工核查，排除"价值陷阱"（业绩暴雷导致的合理下跌）。

## 二、逐项指标详解

### （一）长期估值条件

#### 1. 市盈率 PE —— 满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | 12.02 倍 |
| 历史分位 | 0.05% |
| 策略门槛 | 分位 ≤ 10% |

- **含义**：PE = 总市值 / 净利润（或股价 / 每股收益），衡量为每 1 元利润支付的价格。
- **历史分位 0.05%**：当前 PE 只比历史上 0.05% 的交易日贵，即处于**自身历史估值的极端底部**（比 99.95% 的时间都便宜）。
- **判定**：远低于 10% 门槛 → 满足。

#### 2. 市净率 PB —— 满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | 2.73 倍 |
| 历史分位 | 0.05% |
| 策略门槛 | 分位 ≤ 10% |

- **含义**：PB = 总市值 / 净资产，衡量为每 1 元账面净资产支付的价格，适用于重资产/制造业公司。
- **解读**：与 PE 同样处于历史极端低位，说明便宜不是单一指标的偶然。
- **判定**：满足。

#### 3. 市值 / 经营现金流 —— 未满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | 9.24 倍 |
| 历史分位 | 16.46% |
| 策略门槛 | 分位 ≤ 10% |

- **含义**：以经营现金流替代利润进行估值（类 PCF 指标）。现金流比利润更难被会计手法修饰，是估值的"验真器"。
- **解读**：当前分位 16.46%，虽也偏便宜，但未达到 ≤10% 的严格标准——现金流端的估值压缩没有利润端那么极端。
- **判定**：**未满足**，是 6 项中唯一未通过的一项。

### （二）短期超跌条件

#### 4. 距 52 周高点回撤 —— 满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | -50.46% |
| 策略门槛 | ≤ -25% |

- **含义**：现价相对过去 52 周（一年）最高价的跌幅。
- **解读**：-50.46% 即"腰斩"，远超 -25% 门槛，属于深度回撤。

#### 5. 20 日相对沪深 300 —— 满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | -20.36 个百分点 |
| 策略门槛 | ≤ -15 个百分点 |

- **含义**：近 20 个交易日个股涨跌幅 − 同期沪深 300 指数涨跌幅（超额收益）。
- **解读**：-20.36pp 表示个股显著跑输大盘 20 个点以上，排除了"是大盘整体下跌拖累"的情况，属于**个股层面的相对超跌**。

#### 6. 5 日跌幅异常程度 Z —— 满足

| 项目 | 数值 |
| --- | --- |
| 当前读数 | -3.48 |
| 策略门槛 | ≤ -2.50 |

- **含义**：Z 分数 =（近 5 日跌幅 − 该股历史 5 日跌幅均值）/ 历史标准差，衡量近期下跌在统计上有多"异常"。
- **解读**：-3.48 表示本次 5 日下跌偏离正常水平 3.48 个标准差。在正态分布假设下，|Z|>3 的概率不足 0.3%，属于统计学意义上的**异常暴跌**。

## 四、策略设计逻辑解读

1. **估值看分位而非绝对值**：不同时期利率环境、行业景气不同，绝对 PE 无可比性；与"自己的历史"比分位更稳健。
2. **超跌看三个角度**：
   - 时间维度（52 周回撤）——跌得深不深；
   - 横截面维度（相对沪深 300）——是不是个股独有的下跌；
   - 统计维度（Z 分数）——是不是恐慌性的异常抛售。
   三者同时满足，大概率是"错杀"而非"价值回归"。
3. **左侧信号 + 右侧确认**：先出筛选信号，再等 5% 反弹确认企稳，兼顾赔率和胜率。
4. **人工复核兜底**：防止基本面恶化（如业绩变脸、行业逻辑破坏）导致的"越跌越贵"价值陷阱。

###  以下是另一部分新内容，与上面无关



人工复核的核心目标是回答一个问题：**"这次下跌是市场错杀，还是基本面真的恶化了？"** 围绕这个问题，复核分四步：

## 第一步：定位下跌原因（先定性）

先搞清楚这波 -50% 回撤 + 近期异常暴跌的驱动因素，常见三类：

| 类型          | 特征                                               | 结论倾向               |
| ------------- | -------------------------------------------------- | ---------------------- |
| 系统性/情绪性 | 行业板块同步下跌、宏观流动性收紧、无个股利空       | 错杀概率大，可继续复核 |
| 行业性        | 行业景气下行（如产能过剩、价格战），但公司份额稳固 | 谨慎，看周期位置       |
| 公司性        | 业绩暴雷、大客户流失、诉讼、管理层问题             | 高危，大概率放弃       |

对宁德这类标的，重点查：近期公告、业绩预告、券商研报、新闻舆情，确认下跌是否有"公司独有"的硬伤。

## 第二步：核查盈利质量（防报表陷阱）

低 PE 可能是假的——分母（利润）可能虚高或即将崩塌：

1. **利润 vs 现金流背离**：净利润是否持续 > 经营现金流？（本次"市值/经营现金流"未达标，更要重点查）若利润高但现金流跟不上，可能有应收账款堆积或利润调节。
2. **盈利来源**：利润里有多少是一次性收益（卖资产、政府补贴、公允价值变动）？看扣非净利润趋势。
3. **盈利趋势**：最近 2-4 个季度营收/利润增速是否断崖式下滑？低 PE 若是"盈利即将负增长"的预期，就是典型的价值陷阱——**PE 越低可能越危险**（E 在崩）。
4. **毛利率/净利率趋势**：连续多个季度下滑 = 竞争恶化信号。

## 第三步：核查资产负债表与行业逻辑

1. **偿债风险**：有息负债率、短期债务/货币资金、利息保障倍数。高杠杆公司暴跌后容易触发债务危机。
2. **资产质量**：存货是否激增（跌价风险）、商誉占比（减值风险）、应收账款账龄。
3. **行业逻辑是否破坏**：这是最关键的一问——
   - 需求端：行业总需求还在增长吗？（如动力电池装机量）
   - 竞争格局：公司市占率是升是降？护城河还在吗？
   - 技术路线：是否存在被替代风险？
   
   **如果行业逻辑已破坏，估值再低也不买**——历史分位是基于"历史会重演"的假设，逻辑破坏后历史分位失效。

## 第四步：交叉验证与结论

- **券商一致预期**：未来 1-2 年盈利预测是在上调还是下调？预测仍在下修 = 分析师还在"追跌"，底部未到。
- **内部人行为**：大股东/高管近期是增持还是减持？回购是否真金白银？
- **机构持仓**：公募/北向是在撤离还是抄底？

## 复核结论输出（建议三选一）

| 结论       | 条件                                             | 动作                       |
| ---------- | ------------------------------------------------ | -------------------------- |
| 通过       | 下跌为情绪/系统性，盈利现金流匹配，行业逻辑未变  | 等 5% 反弹确认后按策略入场 |
| 有条件通过 | 有瑕疵但可量化（如一次性计提）                   | 降低仓位或提高反弹确认门槛 |
| 否决       | 盈利持续恶化、行业逻辑破坏、现金流与利润长期背离 | 放弃，无论信号多强         |

**一句话原则**：量化信号告诉你"便宜了"，人工复核要确认"它配便宜还是不该便宜"。价值陷阱的共同特征是——**下跌有充分的、持续恶化的基本面理由**，复核就是要把这种标的剔除出去。
