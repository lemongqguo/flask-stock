### 生产环境安装部署
# 警告：Flask 内置的开发服务器（Werkzeug）性能低且不安全，严禁直接用于生产环境。
# 生产使用 gunicorn，配置见项目根目录的 gunicorn.conf.py。
#
# 安装：
#   pip install -r requirements.txt        # requirements.txt 里已经包含 gunicorn
#
# 启动（在项目根目录执行，日志打到终端）：
#   gunicorn -c gunicorn.conf.py app:app
#
# 注意：本项目**必须单进程**（gunicorn.conf.py 里已固定 workers = 1），
# 不要再加 -w 4——告警冷却、运行时 AI 密钥、监控线程都是进程内状态，
# 多进程会让它们全部失效，且每个 worker 各起一个监控线程。
# 需要更高并发时改线程池：GUNICORN_THREADS=16 gunicorn -c gunicorn.conf.py app:app
